# Thales AGILAB

Repository: https://github.com/ThalesGroup/agilab

AGILAB's run-evidence contract is a natural place to test an optional proof-backed run receipt. A narrowly scoped adapter could record the workflow identifier, code or image digest, policy decision and final outcome without recording notebook contents or credentials. The useful question is whether a portable receipt improves reproducibility and review without coupling AGILAB to a hosted verifier.
