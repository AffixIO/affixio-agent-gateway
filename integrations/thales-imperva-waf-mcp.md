# Thales Imperva Cloud WAF MCP server

Repository: https://github.com/ThalesGroup/imperva-cloud-WAF-MCP-server

This repository is read-only today. A safe experiment is therefore limited to authorising and attesting read operations: tool name, tenant/site reference hash, query policy and response digest. It should not add write operations or bypass Imperva permissions. The gateway can sit beside the MCP server and fail closed when a tool is not explicitly allowed.
